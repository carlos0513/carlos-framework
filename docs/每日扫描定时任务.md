### 3. 安全检查清单（重点关注）

- [ ] 是否存在 MD5/SHA1 等弱密码编码器
- [ ] ObjectMapper Visibility 配置是否过宽（ANY → 应 PUBLIC_ONLY）
- [ ] Redis 中是否存储敏感 Token 明文
- [ ] WebClient/RestTemplate 是否配置超时
- [ ] 静态工具类（RedisUtil 等）是否导致难以测试
- [ ] 匿名内部类是否影响 Native Image 编译
- [ ] Map/Cache 是否有内存泄漏风险（无过期清理）

### 4. 技术趋势扫描

搜索以下技术的最新版本动态（通过 web_search）：

- Spring Boot / Spring Cloud / Spring Cloud Alibaba 最新版本
- MyBatis-Plus、ClickHouse Java Client、Redisson、Hutool、MapStruct
- Java LTS 版本（21 / 24）
- 与当前框架版本对比，标注升级差距
